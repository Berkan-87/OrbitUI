# OrbitAuth - Ultimate Space UI Bundle

Thank you for purchasing the OrbitAuth Ultimate Bundle! This package includes 5
premium, fully responsive UI components built with a consistent deep-space
"Wormhole" design language.

## 📦 What's Included

This bundle contains 5 separate folders. Each folder is a standalone project and
can be used independently.

1. **01-Login:** A dark-mode login page with an interactive black hole/wormhole
   animation.
2. **02-Register:** A sign-up page featuring the interactive wormhole and a
   dynamic password strength meter.
3. **03-404-Page:** A fun error page featuring a "broken" wormhole. Clicking the
   button restores the orbit and turns on the light.
4. **04-Pricing:** A 3-tier pricing table (Cadet, Commander, Admiral) with
   interactive hover effects and orbital glows.
5. **05-Profile:** A user settings dashboard with an orbital avatar, stats, and
   a functional Dark/Light mode toggle switch.

## 🛠️ Tech Stack & Features

- **Zero Dependencies:** Pure HTML, CSS, and Vanilla JavaScript. No React, Vue,
  Tailwind, or jQuery required.
- **3 Built-in Themes:** Supernova Red, Nebula Blue, and Toxic Green (switchable
  via Mac-style window controls).
- **Light/Dark Mode:** Included natively in the Profile component.
- **Glassmorphism:** Modern backdrop-blur effects.
- **Fully Responsive:** Adapts perfectly to mobile, tablet, and desktop.
- **Easy Customization:** All colors are controlled by CSS variables.

## 🚀 How to Use

1. Open the folder of the component you want to use (e.g., `01-Login`).
2. Open `index.html` in your browser to preview it.
3. To integrate into your project:
   - Copy the HTML structure.
   - Link the `style.css` in your `<head>`.
   - Include `script.js` before the closing `</body>` tag.

## 🎨 Switching Themes Programmatically

By default, users can switch themes using the Mac-style window controls (top
right). If you want to force a specific theme on page load, add one of the
following classes to the `<body>` tag:

- **Nebula Blue:** `<body class="theme-blue">`
- **Toxic Green:** `<body class="theme-green">`
- _(Leave empty for Default Supernova Red)_
